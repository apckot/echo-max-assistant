# Stage3 audio admission

No real audio/STT, MAX canary or deployment is authorised at checkpoint60. Local verification uses synthetic non-speech byte fixtures, FakeHTTP/FakeCodec/FakeSTT. Neither transcript accuracy nor sandbox availability on a live host is established by those fixtures.

OpenAI receives the recording itself. Disclosure/explicit processor-specific audio consent and user declarations (own dictation, no prohibited data or unconsented third parties) are separate from successful format checks. Region/category/retention profile flags must each permit the external route. Content-analysis-required policy denies because no local ASR/privacy model exists. These checks do not prove absence of all personal data. Missing/revoked consent, changed revision, stopped/deleting account, fence, unverified source, unsafe URL, oversize/duration or codec errors deny. No mandatory repeated voice confirmation.

Only exact operator-allowlisted HTTPS MAX media origins are eligible. Public DNS answers are validated and the selected address is pinned to TLS request; redirects, private/reserved ranges, credential-bearing URLs, response compression and oversized streams fail closed. Attachment upload token is not a download credential and is never forwarded. Actual signed-URL/origin behavior remains a later authorised live-canary prerequisite; do not silently add hosts or credential forwarding when denied.

Decoder: Linux bubblewrap private user/PID/network/IPC namespaces, dropped capabilities, cleared environment, no project/config mounts; ffmpeg only sees /work/input copied through stdin into private tmpfs. Resource caps:5s CPU/timeout,512MiB address space,64processes, single codec/filter thread, raw input25,000,000B. PCM output is counted through a private pipe, mono16kHz/s16le,≤50MiB/20min. A simultaneous lossless FLAC output≤25,000,000B strips input metadata and is checked for16kHz/mono/16bit before STT. Nothing decodes outside the sandbox. Missing tools or unavailable user namespaces deny; no native unsandboxed fallback. Docker image includes ffmpeg/bubblewrap/util-linux, but host namespace qualification belongs to authorised release/canary, not a claim made by FakeCodec tests.

Raw and normalized audio remain ephemeral process memory / decoder private tmpfs, never PostgreSQL, Git, backup or host temp files. tmpfs disappears with the decoder; ApprovedAudio is an opaque in-process capability with30min hard read expiry and buffer zeroing. Transcript commit/failure releases buffers; restart cannot recover old buffers. Before STT-start it may re-download the immutable source; after a durable STT-start without transcript it must report uncertain and never redispatch. Durable metadata/transcripts use FORCE RLS and account erasure/retention. Consent revocation is checked again after download/codec and immediately before STT admission; already-started external processing cannot be recalled by a local flag.
