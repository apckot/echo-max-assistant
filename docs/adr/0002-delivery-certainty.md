# ADR2: Certainty before retry

An admitted attempt is durable before transport. A confirmed provider message ID means sent. A proven pre-send rejection means not_sent and can retry under bounded policy. Any timeout/transport ambiguity after potential consumption means uncertain; never blindly retry. Immutable started/completed attempt facts retain the admitted owner/generation. Lease expiry revokes authority, not network history. Stop cancels unadmitted work; admitted work must settle certainty. Restored pending/sending/retry is uncertain_restore and never automatically sent; old inbound materialized after reopen receives the same quarantine. Prefer one possibly omitted old reply over a duplicate caused by restored state. Future product reconciliation is outside Stage1.
